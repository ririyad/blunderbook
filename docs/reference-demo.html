Blunder Log

Your mistake library, built from any game you play

Demo. PGN import and FEN quick entry are real: Stockfish 17.1 runs in your browser and finds the blunders. Lichess and Chess.com sync is simulated here. The 6 entries already in the log are engine-checked samples. Everything you add is saved only in this browser.

    Import PGN

    From any source: a .pgn file from Lichess, Chess.com or ChessBase, a tournament download, or an over-the-board game you typed up from your score sheet. A file can hold many games.

    Choose .pgn file
    Comma-separated. Used to work out which side you played. If no name matches, the app asks.

    Quick entry from a FEN

    Only have one position, e.g. a game with no score sheet? Paste its FEN, play the move you made, and the engine checks it.

    Tap the piece you moved, then its square.
